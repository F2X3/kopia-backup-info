# Kopia Backup — public information

Two static technical pages for a personal Kopia + rclone configuration using the Google Drive `drive.file` scope.

Owner: F2X3. This is not an official Kopia or rclone website.

- Homepage: https://f2x3.github.io/kopia-backup-info/
- Privacy: https://f2x3.github.io/kopia-backup-info/privacy.html
- Personal-use terms: https://f2x3.github.io/kopia-backup-info/#terms

The repository contains public descriptions only. Do not add backup data, personal notes, OAuth credentials, tokens, repository passwords, or local configuration files.

Publish from the `main` branch, `/ (root)` folder in Settings → Pages. The `.nojekyll` file disables Jekyll.
