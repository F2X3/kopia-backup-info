Kopia Backup

Личная конфигурация для резервного копирования выбранных папок с компьютера в Google Drive. Владелец и оператор конфигурации — F2X3. Она использует Kopia для создания зашифрованных резервных копий и rclone для передачи файлов.

Как это работает

Владелец выбирает папки в Kopia и разрешает доступ через Google OAuth. Kopia шифрует содержимое резервной копии на компьютере до передачи. rclone загружает файлы репозитория в Google Drive владельца. Для восстановления нужны доступ к репозиторию и пароль шифрования.

Доступ к Google Drive

Запрашивается только разрешение https://www.googleapis.com/auth/drive.file: создавать и обслуживать файлы, созданные этим приложением, или отдельно предоставленные ему пользователем. При этой настройке не запрашивается полный доступ к существующим файлам Drive, Gmail или Google Photos.

Конфигурация предназначена для собственного использования владельцем. Это не сервис хранения для других пользователей. Эти страницы описывают конфигурацию; они не содержат резервные копии и не выполняют вход в Google.

Условия использования

Использование предназначено только для владельца конфигурации. Для Kopia, rclone, Google Drive и GitHub действуют условия их поставщиков. Владелец отвечает за выбранные папки, доступное место в Drive, сохранность пароля и проверку восстановления. Этот проект не предоставляет отдельного соглашения об уровне обслуживания.
