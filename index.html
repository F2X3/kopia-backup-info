Kopia Backup

A personal configuration for backing up selected folders from a computer to Google Drive. The owner and operator is F2X3. It uses Kopia to create encrypted backups and rclone to transfer repository files.

How it works

The owner selects folders in Kopia and authorizes access through Google OAuth. Kopia encrypts backup contents on the computer before transfer. rclone uploads repository files to the owner's Google Drive. Restoration requires access to the repository and its encryption password.

Google Drive access

The configuration requests only https://www.googleapis.com/auth/drive.file. This permits access to files created by the application or explicitly made available to it by the user. This configuration does not request full access to existing Drive files, Gmail, or Google Photos.

This configuration is for the owner's personal use. It is not a storage service for other users. These pages describe the configuration; they do not contain backups or perform Google sign-in.
