Kopia Backup

Privacy policy

Last updated: October 14, 2026. This policy covers the personal Kopia Backup configuration operated by F2X3. The configuration uses Kopia and rclone on the owner's computer and Google Drive to store an encrypted repository.

Data access and use

The drive.file permission is used to create, read, update, list, and delete backup repository files accessible to the application. These operations support backup creation, integrity checks, restoration, and repository maintenance.

Encrypted Kopia repository files are transferred to Google Drive together with necessary Drive metadata, such as repository file names, sizes, and operation times. Full access to other existing Drive files is not requested. The configuration does not request access to Gmail, contacts, or Google Photos.

Storage and security

OAuth credentials and tokens are stored locally in the rclone configuration on the owner's computer. They are not published on this website or in the public repository. Kopia encrypts backup contents before upload. The encryption password is not published or transmitted by this website.

The encrypted repository is stored in the owner's Google Drive. Backup retention is determined by Kopia settings. Local Kopia and rclone logs may include paths, operation times, and results; the owner is responsible for protecting these logs.

Sharing with third parties

Google receives encrypted repository files and metadata needed to provide Drive storage. This configuration does not sell Google user data, use it for advertising or model training, or share backup contents with other recipients.

This static website is hosted on GitHub Pages. It contains no forms, analytics scripts, or external assets, other than ordinary links. GitHub may process technical visit data under its privacy statement. This website provides no access to backups.

Revoking access and deleting data

The owner can revoke the application's access in Google's connections settings. Revocation prevents further Drive operations using that authorization; it does not automatically delete existing backups.

To remove all backup data, the owner stops Kopia backup jobs, deletes the repository from Drive, empties the Drive trash if needed, and removes local access configuration and any retained copies. Deleting the repository removes the ability to restore data from it.

Google API policies

The use and transfer of information received from Google APIs are subject to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

This page will be updated if access permissions or data handling change. Questions about this policy can be submitted through the repository's Issues page. Do not post personal data, backup files, passwords, or tokens in an issue.
